# Экспертная система анализа конфиденциальности

Лабораторная работа № 2 по дисциплине «Информационная безопасность и защита информации».

Программа анализирует русскоязычное описание ситуации, извлекает субъектов, получателей, виды конфиденциальной информации, действия и правовой контекст. Затем база правил формирует решение: нарушение, законное действие или необходимость ручной проверки.

## Возможности

- ввод текста с клавиатуры или из TXT-файла;
- анализ коммерческой, налоговой, банковской и врачебной тайны, а также персональных данных;
- база из 19 правил;
- указание закона, причины и рекомендуемого действия;
- уточняющие вопросы при недостатке данных;
- безопасное журналирование без сохранения исходного текста;
- обработка пустого текста и отсутствующего файла;
- 15 автоматических тестов.

## Структура

- `main.py` — консольное меню;
- `analyzer.py` — извлечение фактов;
- `rules.py` — правовые правила и логический вывод;
- `logger.py` — безопасное журналирование с SHA-256-идентификатором;
- `test_system.py` — автоматические тесты;
- `test_cases.txt` — примеры ситуаций;
- `security_log.txt` — создаётся после первого анализа.

## Запуск

```bash
python main.py
```

## Тестирование

```bash
python -m unittest test_system.py -v
```

Дополнительные библиотеки устанавливать не требуется.
